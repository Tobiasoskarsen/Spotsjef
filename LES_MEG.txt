SPOTSJEF – SMARTE RÅD (vær + strøm)
====================================

En regelmotor som kombinerer vær og strøm til 3-4 treffsikre råd.
Ingen AI, ingen kostnad – ren logikk på data du allerede henter.

Lag branch:
  git checkout -b rad

NYE FILER (relativt til spotsjef/):
  lib/rad.ts            <- regelmotoren (4 regler)
  components/RadKort.tsx <- viser rådene

TO SMÅ ENDRINGER I app/page.tsx:

1. Importer øverst:
     import { lagRad } from '@/lib/rad'
     import RadKort from '@/components/RadKort'

2. Beregn rådene (sammen med de andre utledede verdiene, f.eks.
   rett før "return ("). Krever at du allerede har `vaer`-state
   fra vær-steget:
     const rad = lagRad(priser, vaer)

3. Vis kortet i "I dag"-fanen, gjerne ØVERST så det er det første
   brukeren ser – rett etter <Tabs ...> eller først i idag-blokken:
     <RadKort rad={rad} tema={tema} />

JUSTERE REGLENE:
Alle reglene ligger i lib/rad.ts, hver med en kommentar (REGEL 1-4).
Du kan enkelt:
  - endre terskler (f.eks. "billig" = under 80% av snitt)
  - endre tekstene
  - legge til egne regler (kopier mønsteret, gi den en prioritet)
prioritet styrer rekkefølgen – høyere vises først, maks 4 vises.

TEST:
  npm run dev
  Rådene endrer seg med priser, vær og klokkeslett. For å se ulike
  råd kan du bytte sone (annen pris + vær) eller teste på ulike
  tider av døgnet.

NÅR FORNØYD:
  git add .
  git commit -m "Legg til smarte vaer+strom-rad"
  git checkout main
  git merge rad
  git push
