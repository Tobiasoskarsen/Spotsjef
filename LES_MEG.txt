SPOTSJEF – NYTT SKANDINAVISK DESIGN
====================================

Lag en ny branch først, så live-siden er trygg mens du tester:
  git checkout -b design

FILER SOM SKAL INN (relativt til spotsjef/):

  lib/theme.ts            <- ERSTATT (ny palett + getColorSterk)
  components/*.tsx        <- ERSTATT alle 8
  app/page.tsx            <- ERSTATT
  app/layout.tsx          <- ERSTATT (legger til Figtree-font)
  app/globals.css         <- ERSTATT (font + reset)

UENDRET (trenger ikke kopieres på nytt, men er med for sikkerhets skyld):
  lib/types.ts, lib/constants.ts, lib/priser.ts, lib/useAnimatedNumber.ts

VIKTIG OM layout.tsx:
Din gamle layout.tsx kan ha hatt andre fonter (Geist) importert fra
create-next-app. Den nye erstatter alt og bruker Figtree i stedet.
Hvis du hadde tilpasninger i layout.tsx, sjekk dem mot den nye.

VIKTIG OM globals.css:
Den nye er minimal (font + reset). Hvis din gamle globals.css hadde
Tailwind-direktiver (@tailwind ...) som du faktisk bruker, må de beholdes.
Men denne appen styles med inline-styles, så Tailwind brukes neppe.
Sjekk: hvis appen ser helt ustylet ut etter bytte, legg Tailwind-linjene
tilbake øverst i globals.css.

FONTEN:
Figtree lastes automatisk av Next.js via next/font/google – ingen
ekstra installasjon trengs. Krever bare internett ved bygging.

TEST:
  npm run dev      (sjekk lys + mørk modus, alle faner)
  npm run build    (fang type-feil før Vercel)

NÅR DU ER FORNØYD:
  git add .
  git commit -m "Nytt skandinavisk design"
  git checkout main
  git merge design
  git push
